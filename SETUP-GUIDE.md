# Setup Guide (5 minutes)

Your profile repo is: github.com/g2rindian2005-cyber/g2rindian2005-cyber   (already exists - public)

## Step 1 - Upload everything
1. Unzip this package.
2. Open github.com/g2rindian2005-cyber/g2rindian2005-cyber
3. Click Add file -> Upload files.
4. Drag in ALL of these (keep the folder structure):
   - README.md
   - assets/ (folder with all PNGs)
   - .github/ (folder with workflows/snake.yml)
   Tip: if the web uploader hides the .github folder, create it by Add file -> Create new file,
   type  .github/workflows/snake.yml  as the name, and paste the contents of snake.yml.
5. Commit directly to main. Replace the old README.md when asked.

## Step 2 - Edit your details in README.md
- Replace YOUR-LINKEDIN-ID and YOUR-EMAIL@gmail.com.
- Change the featured projects: repo=terraform-practice etc. -> your 4 best repos.
- Edit the "profile.yaml" block so every line is 100% true for you.

## Step 3 - Turn on the contribution snake
1. Repo -> Settings -> Actions -> General -> Workflow permissions -> Read and write -> Save.
2. Actions tab -> "Generate Contribution Snake" -> Run workflow.
3. Wait ~1 min. The snake image appears automatically after that.

## Step 4 - Make it look great
- Pin your 6 best repos (Customize your pins) and give each a clear description and topics.
- Write a README in each pinned repo with architecture diagram, steps and screenshots.
- Keep committing - the stats cards and graph fill up with activity.

## Notes
- Stats cards load from public services (vercel.app / demolab.com). If one shows an error or is blank,
  wait a few minutes and refresh - they are sometimes rate limited.
- Hard refresh with Ctrl + F5 after committing.
- Images in /assets are rounded dark cards, so they look right in both GitHub light and dark mode.
- Editable SVG source of the banner is not required on GitHub; PNGs are what get displayed.
